# 🏙️ Fix My City AI – Smart City Civic Portal

### Report Issues. Fix Your City.

Fix My City AI is a Smart City Civic Complaint Management System designed to connect citizens with municipal authorities. It provides a digital platform where citizens can report public problems, track complaint progress, and contribute towards building cleaner, safer, and smarter cities.

## 🌟 Features

### 👤 Citizen Portal
- Citizen registration and login.
- Report civic problems with descriptions.
- Upload images as complaint evidence.
- Attach current GPS location.
- Select complaint categories and localities.
- Track complaint status and progress.
- Receive notifications.
- Submit reviews and feedback.
- Earn reward points through citizen participation.
- View the citizen leaderboard.

### 🏛️ Admin Portal
- Monitor all citizen complaints.
- View city-wide statistics.
- Analyze area-wise complaints.
- Manage complaint categories.
- Manage chatbot FAQs.
- Monitor complaint resolution progress.

### 👷 Municipal In-Charge Portal
- View complaints assigned to a locality.
- Manage assigned complaints.
- Update complaint status.
- Add remarks and resolution details.
- Submit completion evidence.

### 🗺️ Smart City Features
- Interactive smart city map using Leaflet.
- GPS-based complaint locations.
- Nearby complaint identification.
- Searchable locality selection.
- Complaint filtering by category and location.
- Multilingual interface.

### 🎨 Additional Features
- Light and dark mode.
- Responsive design for mobile and desktop.
- English, Tamil, and Telugu language support.
- Interactive chatbot for common queries.
- Complaint status tracking timeline.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `new.html` in your web browser.
4. Select the Citizen Portal or Admin Portal.
5. Explore the available features.

No additional installation is required for the basic HTML demo.

## 🎯 Project Objective

The main objective of Fix My City AI is to improve communication between citizens and municipal authorities through a transparent digital complaint management system.

It aims to:
- Encourage citizen participation.
- Improve civic issue reporting.
- Make complaint tracking easier.
- Support locality-based complaint management.
- Promote smart and sustainable cities.

## ⚠️ Note

This project currently uses browser-based LocalStorage for data storage. It is a front-end demonstration and does not provide a production-ready backend or secure multi-user database.

Some advanced features listed as future enhancements require additional implementation.
